# KhalidXHost — Fly VPS Manager (Web)

Website + REST API to create and manage VPS machines (Fly Machines) on each user's own Fly.io account.
Built by **@khalid_dev**.

## What's inside
- **Website**: landing page, register/login, user dashboard (create VPS wizard, start/stop/restart/delete, SSH details, Fly token linking).
- **API** (`/api/v1/*`): for people building their own VPS app. Needs an API key **issued by the owner** from the admin page — until then the account's API is locked.
- **Admin console** at `/khalid` (hidden, password protected): users, API on/off switch, generate/revoke keys, block users, reset passwords, all VPS, activity log.
- Docs for users at `/docs`.

## Deploy on Render
1. Push this folder to a GitHub repo (see `.gitignore`, no secrets are in the code).
2. Render → **New → Blueprint** (uses `render.yaml`) or **New → Web Service** with:
   - Build: `pip install -r requirements.txt`
   - Start: `uvicorn app.main:app --host 0.0.0.0 --port $PORT --proxy-headers --forwarded-allow-ips='*'`
3. Set environment variables in the Render dashboard:
   | Var | Value |
   |---|---|
   | `ADMIN_PASSWORD` | your admin password (**required**) |
   | `DATABASE_URL` | Postgres URL (**strongly recommended**, see below) |
   | `SECRET_KEY`, `ENCRYPTION_KEY` | auto-generated by `render.yaml` — keep them stable, changing `ENCRYPTION_KEY` makes stored Fly tokens unreadable |
   | `ADMIN_PATH` | `khalid` (admin URL = `https://your-domain/khalid`) |
4. Custom domain: Render → Settings → Custom Domains → add `khalidxhost.zone.id`, then create the DNS record Render shows you.

### Database
Render's free web service has an **ephemeral disk** — SQLite would be wiped on every deploy/restart. Use a Postgres `DATABASE_URL`
(free options: Neon, Supabase; or Render Postgres). `postgres://` and `postgresql://` URLs are converted automatically.

## Granting API access
1. User registers on the site and links their Fly token.
2. User contacts @khalid_dev on Telegram.
3. Open `/khalid` → Users → **🔑 Key** → copy the key (shown once) → send it to the user.
   Use the switch in the *API* column to turn their API access on/off at any time.

## Local run
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # edit
uvicorn app.main:app --reload
```

## Notes
- Fly tokens and VPS passwords are encrypted at rest (Fernet); user passwords use PBKDF2; API keys are stored only as SHA-256 hashes.
- Each VPS is Ubuntu 24.04 + OpenSSH + Docker, volume mounted at `/data`, ports 22/80/443/2022/8080 published.
- Per-user VPS limit: `MAX_VPS_PER_USER` (default 5).
