Real VMs with root access — not shared containers. Run what you want.

One-click deploy
Pick region, CPU, RAM and disk. We create the app, volume, machine and public IP for you with live progress.

// api
Build your own VPS app
API access is granted per account by the owner. Get your key, then:

  


# create a VPS
curl -X POST https://khalidxhost.zone.id/api/v1/vps \
  -H "Authorization: Bearer kx_your_api_key" \
  -H "Content-Type: application/json" \
  -d '{"name":"my-panel","region":"iad","cpus":2,"memory_mb":4096,"storage_gb":20}'
